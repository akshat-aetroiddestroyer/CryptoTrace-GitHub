    Prevention layer · client-side guard

    Browser extension — real-time address safety

    Manifest V3 content-script that detects 0x wallet addresses in the live DOM and clipboard, queries the CryptoTrace Suspect Registry API, and injects a hard on-screen warning before the user sends funds — the same idea as Safe Browsing, but for crypto addresses.

    Detect

    DOM + clipboard scan

    Regex 0x[a-fA-F0-9]{40} on text nodes, inputs, and copy/paste events.

    Query

    Registry API ≤ 200ms

    Single HTTPS lookup against shared suspect wallet registry used by investigators.

    Warn

    Hard live-screen banner

    Full-width intercept bar + red highlight on the address; never auto-signs transactions.

    Privacy

    For users · daily use

    How to apply it in practice

    • Chat / Telegram / WhatsApp Web

      When a scammer pastes a wallet address, the extension highlights it and shows the banner before you copy-pay.

    • Fake airdrop / claim sites

      Contract or payout addresses on the page are scanned automatically; high-risk hits open the hard modal.

    • Exchange deposit screens

      Confirms you are not pasting a known fraud collection address as a “deposit” instruction from a phishing page.

    • Clipboard guard

      If you copy an address, a toast validates it against the registry within one network round-trip.

    The extension never broadcasts transactions, never asks for seed phrases, and never injects signing requests.

    For judges · evaluation note

    What “hard warning on live screen” means

    1. Detect on the live page

    Content script runs on page load and on DOM mutations (chat messages appearing live). Flagged addresses are underlined in red in-place.

    2. Non-dismissible priority banner

    For high-risk registry hits, a full-width red banner pins to the top of the viewport with risk score, case count, and typology — visible while the tab is focused.

    3. Modal intercept (hard stop UX)

    On critical scores, a modal blocks the center of the screen: “DO NOT SEND FUNDS” + Abort. User must consciously dismiss; the goal is to break the scam’s urgency loop.

    // decision logic (simplified)

    if (registry.hit && riskScore >= 80) → HARD_MODAL + TOP_BANNER + icon badge

    else if (registry.hit) → TOP_BANNER + inline highlight

    else → silent allow (optional green toast)

    // never: auto-send, auto-sign, keylogging, full-page upload
